# posh-git (placeholder)

This directory is a placeholder for the **posh-git** module.  
If you wish to use `posh-git`, clone or copy the module into this folder, or let the installer copy it from another source.

The installer (`install.ps1`) will copy the contents of this directory to:

```
$HOME\Documents\PowerShell\Modules\posh-git
```

You can then customize the module or replace it with the official version.
